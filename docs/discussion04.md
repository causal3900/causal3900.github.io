### Exchangeability in DAGs {-}

- Exchangeability requires statistical independence $A\perp\!\!\!\perp Y^a$
- Two nodes are dependent if and only if they are connected by an unblocked path
(path with no colliders)

<center>Exchangeability holds if all unblocked paths between $A$ and $Y$ are causal paths that point from $A$ to $Y$</center>


#### In-class Assignment 1 {-}

For each DAG determine whether exchangeability holds:

1. List all paths between $A$ to $Y$
2. Cross out the blocked paths
3. Exchangeability holds if all remaining paths are causal
